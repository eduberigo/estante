# Estante

Explorador de partituras para Android (Samsung S26 Ultra e Tab S8 Ultra).

**Fase 1:** pastas reais do aparelho, miniaturas, pré-visualização, leitor em tela cheia e busca por nome/pasta.
O app só lê os arquivos: nada é movido, renomeado ou apagado.

## Instalar
1. Abra **Releases** neste repositório pelo navegador do tablet.
2. Baixe o `Estante-0.1.N.apk` mais recente e toque nele.
3. Na primeira vez, permita "Instalar apps desconhecidos" para o navegador.
4. Ao abrir o app, conceda "Acesso a todos os arquivos".

Cada `push` na branch `main` gera uma nova versão automaticamente (GitHub Actions).
